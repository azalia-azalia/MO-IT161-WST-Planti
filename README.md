# Planti: The Plant Tracker Management System

Planti is a browser-based plant tracking application designed to help beginner plant owners and gardening enthusiasts organize and manage their plants.

## Features

- Add and manage plant records.
- View plant information and care requirements.
- Search and filter plants.
- Update plant details and health status.
- Store data using the browser's local storage.

## Tech Stack

- HTML
- CSS
- JavaScript
